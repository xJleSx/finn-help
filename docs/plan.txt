Что УБРАТЬ (over-engineering, которое ест ресурсы)
1. Celery — полностью выпилить
Почему: у тебя уже есть inline scheduler (src/scheduler/service.py, 489 строк). Celery дублирует его функциональность, добавляет Redis как обязательную зависимость и усложняет деплой.
Что делать:
Перенести 14 задач из Celery beat в scheduler/tasks.py
Использовать Redis только для кэша и pub/sub (SSE)
Убрать src/tasks/, celery worker, celery beat из docker-compose
Экономия: −1 сервис в Docker, −1 зависимость, −1 точка отказа.
2. Микро-модули анализа, которые не используются
Что убрать:
src/analysis/real_yield.py — не интегрирован, дублирует after_tax_yield.py
src/analysis/fx_exposure.py — не интегрирован, портфель только в рублях
src/analysis/onchain_sentiment.py — крипта? У тебя MOEX-only. Если нет крипты — выпилить.
src/social/vk.py + src/social/pulse.py — если VK token невозможно получить стабильно, это мёртвый код
Правило: если модуль не вызывается из service.py или API routes → в архив.
3. Брокеры-заглушки (BCS, Finam, Alor)
Почему: 3 брокера = 3 интерфейса без реализации. Это не «архитектура на будущее», это техдолг.
Что делать:
Оставить только BaseBroker (абстракцию) и TBankBroker (реализацию)
BCS/Finam/Alor — удалить файлы. Когда понадобится — добавишь за 2 часа по шаблону T-Bank
Экономия: −3 файла, −1 папка, чище код.
4. NLQ (Natural Language Query)
Почему: нет команды в Telegram, используется только через API. Если нет пользователей API → мёртвый код.
Что делать:
Выпилить src/interfaces/nlq/
Если нужно — вернуть как /ask команда в Telegram, но сразу с Groq-роутингом, без отдельного движка
5. ML Ensemble (CatBoost, LightGBM, XGBoost, Prophet)
Почему: ты сам сказал — «quality неизвестен, нет A/B теста». Это не ML-продукт, это облигационный портфельный трекер.
Что делать:
Оставить одну модель (CatBoost — самая быстрая и предсказуемая)
Остальные — в ml/archive/
Или вообще заменить на простые эвристики: «если YTM > 15% и рейтинг AAA → BUY»
Честно: для облигаций ML не нужен. YTM, рейтинг, дюрация — это детерминированные формулы. ML имеет смысл только для акций/сентимента.
🟡 Что УПРОСТИТЬ (дублирование и сложность)

9. Scheduler (inline) → заменить на APScheduler
Сейчас: самописный цикл с _is_time(), который может пропускать моменты.
Решение: APScheduler (уже есть в Python ecosystem):
Python
from apscheduler.schedulers.asyncio import AsyncIOScheduler

scheduler.add_job(morning_brief, 'cron', hour=9, minute=0)
scheduler.add_job(check_contributions, 'cron', day=25, hour=10, minute=0)
Почему: надёжнее, не пропускает, не нужен PID-lock.

10. Таблица defaulted_bonds — MUST HAVE
Сейчас: survivorship bias в бэктесте.
Решение:
sql
CREATE TABLE defaulted_bonds (
    isin VARCHAR(12) PRIMARY KEY,
    default_date DATE NOT NULL,
    recovery_rate DECIMAL(5,2),
    rating_at_default VARCHAR(10),
    sector VARCHAR(50),
    prices_before_default JSONB  -- цены за 90 дней
);
Данные: забить вручную 50 дефолтов 2024–2025 (2 часа работы). Источники: АКРА отчёты, Cbonds.
